# ⚖️ LegalAssist AI

**AI-powered legal document simplification, contract comparison, and clause clarification — making legal access affordable for everyone.**

Built for **PromptWars 2026** | Problem Statement: *AI for Legal Assistance & Access*

## 🎯 What It Does
LegalAssist AI puts an AI legal co-pilot in your pocket — helping freelancers, tenants, and small business owners understand contracts before signing them.

- **Simplify** — Upload any contract and get an instant 0–100 Risk Score, red-flag detection, and plain-language breakdown.
- **Compare** — Semantic diff between two contract versions with a Balance-of-Power indicator.
- **Clarify** — Deep-dive into tricky clauses with real-world analogies and ready-to-send redline scripts.
- **Multilingual** — Full translation support in English, Hindi (हिंदी), and Gujarati (ગુજરાતી).
- **Secure** — Built-in Prompt Injection Defense and safety layers ensuring API keys are never exposed.

## 🛠️ Tech Stack
* **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons
* **Backend:** Node.js, Express (100% Server-side API processing)
* **AI Engine:** Google Gemini API (`@google/genai` SDK - Gemini 3.1 Flash)
